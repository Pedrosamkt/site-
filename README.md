# Plano de Tráfego · Loja Magnífica

Página estática (`index.html`) com a proposta de tráfego pago para a Loja Magnífica: serviços, funcionamento e as duas opções de investimento (R$ 1.400 com bônus / R$ 1.200 sem bônus).

## Publicar na Vercel

Este repositório não está conectado a nenhuma conta Vercel a partir desta sessão — o deploy precisa ser feito pela conta do responsável pelo projeto:

1. Acesse [vercel.com/new](https://vercel.com/new) e importe este repositório GitHub.
2. Ao nomear o projeto, use `planejamento-magnifica` — a Vercel gera automaticamente o domínio `planejamento-magnifica.vercel.app`.
3. Não é necessário configurar build command nem output directory: é um `index.html` estático na raiz.
4. Deploy. O link fica pronto em menos de um minuto.

Se preferir um domínio próprio (ex.: `planejamento.lojamagnifica.com.br`), isso é feito depois em **Project Settings → Domains**, dentro da própria Vercel.
